a learning project

Your own small Netlify.

Push your code, and a small server of mine builds it in a clean box, saves it as a new release, and flips one link so the new site goes live. If anything breaks, it never goes live, and rolling back takes a moment.

See how it works → The six stages

From push to live

1git push
2signed webhook
3build in Docker
4new release folder
5link flips, site is live

The flip is atomic

A visitor sees the old release or the new one, never a half-copied site.

A broken build stays off

The live site only moves after a complete release exists.

Instant rollback

Old releases are kept. Going back is one command, and nothing is rebuilt.

Only signed pushes count

A request is checked before anything in it is read, and an old push can't replace a newer one.

Built in stages

  1. 0 Setup. A server, a web server and Docker.
  2. 1 Serve a folder. Caddy turns a path into a file.
  3. 2 Subdomains. One server, many sites, chosen by name.
  4. 3 Releases and rollback. New folder, then one link moves.
  5. 4 Builds in Docker. A clean, locked-down box for every build.
  6. 5 Webhook. A push deploys by itself.
  7. 6 A pretty face. This page and the dashboard.
Built to learn how deploy platforms work, one layer at a time.
