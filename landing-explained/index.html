The test checks text over the strongest patch of every mist colour (tinted harder than the page ever draws it) and fails if any pair drops below 4.5 : 1, the WCAG level for normal text.

The rules

  • One dark card per page. It is the thing to look at.
  • Pills for actions, chips with a dot for state, glass for grouping. Nothing else.
  • The mist colours are background only, never text. Text is ink, muted or deep.
  • Light type for big headings, regular weight for everything else.
  • The mist drifts very slowly (about a minute per swing), and stays still for people who asked their device to reduce motion.

5 One theme, many copies

What stops a copy going stale? The site test compares every copy with the source and fails with “stale: run scripts/sync-theme.sh”.
FileJob
web/theme/pink.cssthe look: colours, glass, pills, chips, timeline
web/theme/explain.cssextra pieces for these guide pages: diagrams, callouts, code
scripts/sync-theme.shcopies both to where they are used

Try it

Run from the repo folder, inside WSL.

# deploy the landing page as the app "mini-deploy"
python3 scripts/deploy.py deploy mini-deploy web/landing
live: 20261011-153750  (was: 20261011-153732)

# after changing web/theme/pink.css, copy it everywhere
bash scripts/sync-theme.sh

# check copies, contrast, and that nothing phones home
bash scripts/test-sites.sh

Then open http://mini-deploy.localhost:8080.
